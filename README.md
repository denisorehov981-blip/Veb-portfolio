# Веб-портфоліо вчителя інформатики

Індивідуальне практичне завдання з розробки персонального сайту-портфоліо.

## Технічне завдання (ТЗ) на розробку

### 1. Визначення характеру сайту
* Тип: Персональний професійний веб-сайт (веб-портфоліо вчителя).
* Призначення: Демонстрація кваліфікації, методичних матеріалів, конспектів уроків та результатів педагогічної діяльності.

### 2. Стиль та зміст сайту
* Назва проєкту: Веб-портфоліо вчителя інформатики.
* Слоган: Інформатика — це простір для творчості, логіки та інновацій.
* Карта сайту (меню):
  * Головна (index.html) — візитна картка, фото, коротка інформація.
  * Про мене (about.html) — освіта, життєве кредо, інтереси.
  * Методична робота (materials.html) — розробки уроків, презентації, завдання.
  * Контакти (contacts.html) — зворотний зв'язок.

### 3. Технологічна база
* CMS: Відсутня (розробка на чистому коді HTML5 / CSS3 / JavaScript).
* Хостинг: GitHub Pages.
