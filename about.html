Загальні відомості

Освіта: Студент вищого навчального закладу за напрямом підготовки "Цифрові технології в освіті / Інформатика".

Професійне кредо: "Навчати та навчатися одночасно, використовуючи передові технології для розвитку кожної дитини".

Педагогічні інтереси та практика

Під час проходження педагогічної практики особливу увагу приділяю таким напрямкам:

  • Впровадження концепції універсального дизайну в освіті та інклюзивного навчання.
  • Розробка адаптованих дидактичних матеріалів та індивідуальних занять для учнів початкових класів (зокрема для дітей, що потребують додаткових рівнів підтримки).
  • Створення інтерактивних онлайн-курсів на платформах електронного навчання.
  • Використання хмарних сервісів та STEM-технологій на уроках інформатики.

Технічні навички (IT-компетенції)

  • Веб-розробка: Базові знання HTML5, CSS3, архітектури вебсайтів, робота з хостингом GitHub Pages.
  • Електронне навчання: Адміністрування курсів та створення контенту в СУН Moodle.
  • Цифрова грамотність: Робота з інтерактивними дошками, онлайн-тестами та освітніми симуляторами.
